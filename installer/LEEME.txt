Scrinium: instalacion
==================

Necesitas unos 2 GB libres y 4 GB de memoria. No hace falta ser administrador.
La primera vez descarga unos 0,7 GB: herramientas y el modelo de busqueda. Al abrir
Scrinium eliges que modelo escribe las reglas: tu proveedor (recomendado), un servidor
local o el modo aislado. El modelo local propio es opcional (2,5 GB mas, mejor con GPU):

    scrinium tools install local

Para probarlo en 5 minutos, sin modelo ni GPU:

    scrinium demo

Linux y macOS, en una terminal dentro de esta carpeta:

    sh install.sh

Windows, en PowerShell dentro de esta carpeta:

    powershell -ExecutionPolicy Bypass -File install.ps1

Despues, para abrir Scrinium:

    scrinium start

Si algo falla, `scrinium doctor` dice que falta y como arreglarlo.
Para detenerlo: `scrinium stop`. Para ver en vivo todo lo que hace: `scrinium attach`.
Para desinstalarlo todo, datos incluidos: `scrinium uninstall`.
